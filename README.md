# 📊 Human Resources Analytics Dashboard | Tableau

## 📌 Project Overview

What can HR data reveal about an organization's workforce?

This project presents an interactive **Human Resources Analytics Dashboard** developed using **Tableau** to explore workforce trends, employee demographics, hiring and termination patterns, salary distribution, and performance insights.

The dashboard transforms HR data into meaningful visualizations, helping users understand workforce composition and identify key organizational insights.

## 🎯 Project Objectives

- Analyze employee hiring and termination trends.
- Understand workforce distribution across departments.
- Explore employee demographics by gender, age, and education.
- Examine relationships between education and performance.
- Analyze salary patterns across age groups, education levels, gender, and job roles.
- Visualize employee distribution across geographical locations.
- Build an interactive dashboard for effective HR data exploration.

## 📈 Key Dashboard Insights

- **7,984 Active Employees**
- **8,950 Total Hires**
- **966 Employee Terminations**
- Department-wise workforce distribution.
- Gender and age-group demographic analysis.
- Education-level and employee-performance comparison.
- Salary analysis by education, gender, age, and job role.
- Geographical distribution of employees across locations.

## 📊 Dashboard Features

### 1. Employee Overview
Displays key HR metrics, including active employees, total hires, and terminations, along with departmental workforce distribution.

### 2. Demographics
Analyzes employee composition based on gender, age groups, and education levels.

### 3. Education & Performance
Explores employee performance ratings across different educational qualifications.

### 4. Income Analysis
Visualizes salary trends based on education, gender, age, and job roles.

### 5. Location Analysis
Displays geographical workforce distribution and employee allocation across headquarters and branch locations.

### 6. Interactive Visualizations
Includes interactive filters and click-to-filter functionality for dynamic data exploration.
